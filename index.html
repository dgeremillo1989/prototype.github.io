Design and Implementation of a Digital Time-Logging System

Enhanced Customer Session Tracking at Wiijump Philippines

Researchers: Danielle John Cruz, Geremilo Milky, Maitum Palle Section: OLCA333A010 Professor: Mr. Jerico Vilog
Abstract Introduction Methodology Live App Demo

Abstract

Manual time-tracking systems often lack the precision and real-time visibility required for efficient venue management. This study proposes the design and implementation of a centralized, web-based digital time-logging system to automate customer session tracking. The system requires users to input contact details upon entry, enabling seamless monitoring of customer sessions. Furthermore, the system provides stakeholders with a comprehensive administrative dashboard for real-time occupancy monitoring and the ability to generate and export daily analytical reports containing comprehensive customer logs. By digitizing these processes, the proposed solution aims to optimize facility resource allocation, improve customer experience through automated communication, and streamline operational decision-making for management.

Keywords: Web-based Information System, Database Management System (DBMS), Real-time Occupancy Analytics, Data-Driven Decision Making, Administrative Dashboard.

1. Introduction

1.1 Background and Motivation

Currently, Wiijump Philippines relies on a manual, paper-based workflow using stickers and tickets to track customer sessions, which creates a disconnected information flow where attendance records and POS sales data must be tallied manually only after the business day concludes. This dependency on manual entry introduces significant risks regarding data integrity and prevents management from accessing real-time occupancy analytics, effectively blinding them to operational inefficiencies as they happen. This project is critical as it facilitates a transition from reactive record-keeping to proactive, data-driven management by centralizing customer logs and automating session monitoring, ultimately replacing error-prone manual labor with a streamlined digital system that enables real-time decision-making, better resource allocation, and improved operational efficiency.

1.2 Problem Statement

Wiijump Philippines struggles with operational inefficiencies caused by manual, paper-based time-logging, leading to data reconciliation gaps and a lack of real-time occupancy monitoring. The organization faces challenges including inaccurate daily attendance tallies, reliance on manual ticket counting for inventory, and an inability to proactively manage customer session times, resulting in potential overcrowding and inconsistent customer service.

1.3 Scope and Limitations

Scope: The system covers customer registration, session duration tracking, and administrative reporting. It is a web-based information system accessible via any standard device browser.

Limitations: The system does not include a payment gateway and does not utilize hardware sensors (such as turnstiles or RFID gates); it relies on staff or client data input configuration.

2. Methodology & Requirements

The system utilizes an Agile Development Framework to enable component iteration across core building blocks.

Functional Requirements (FR)

  • User session intake registration logs.
  • Real-time automated status calculations.
  • Administrative telemetry analytics overview dashboard.
  • Exportable logs capability (.CSV / Excel framework emulation).

Legal Compliance

In accordance with the Philippine Data Privacy Act of 2012 (RA 10173), the intake system includes active consent architecture frameworks protecting customer PII logs from over-retention.
